# GoScoot QA 實戰演練

GoScoot 智慧共享滑板車系統 — QA 工程師訓練專案

## 系統架構

- **使用者端 (App)**：掃碼解鎖、查看附近車輛、即時電量、信用卡扣款
- **車輛端 (IoT)**：每 10 秒回傳 GPS + 電量，低電量降速/鎖車邏輯
- **營運端 (後台 Web)**：即時軌跡、強制解鎖/鎖定、退費處理
